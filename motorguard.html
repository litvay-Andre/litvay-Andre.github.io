MotorGuard: monitoramento preditivo de motores elétricos via IoT

Sistema supervisório de baixo custo para detectar falhas incipientes em motores monofásicos antes que se tornem críticas.

ESP32
DS18B20
ACS712
Firmware em C++
O problema

Manutenção corretiva custa caro

A manutenção corretiva — feita só depois que o motor falha — gera custos altos e paradas não planejadas. A manutenção preditiva resolveria isso, mas historicamente exige equipamentos caros e complexos. O MotorGuard testa a hipótese de que um microcontrolador simples como o ESP32 já tem processamento suficiente para monitorar variáveis críticas com precisão adequada.

Como funciona

Sensores no motor, dados na nuvem

O núcleo do hardware é um ESP32, escolhido pela conectividade Wi-Fi/Bluetooth nativa e conversor analógico-digital integrado. Um sensor DS18B20 monitora a temperatura da carcaça e um sensor ACS712 mede a corrente elétrica, detectando sobrecarga. O firmware, em C++, faz a leitura e o pré-processamento dos sinais antes de enviá-los para um dashboard web em tempo real.

A validação foi feita em bancada, com um motor de indução monofásico submetido a operação nominal e falhas simuladas.

Os testes confirmaram que o protótipo detecta elevações anormais de corrente e temperatura com estabilidade e baixa latência entre o ESP32 e a interface web, validando o ESP32 como alternativa de baixo custo à manutenção preditiva tradicional. Como próximos passos: interface gráfica dedicada e envio de dados para a nuvem para histórico de manutenções.
